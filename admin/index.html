প্রকাশিত সংবাদ পরিচালনা

ভিডিও নিউজ প্রকাশ

উপরের GitHub Token ব্যবহার করেই ভিডিও সংরক্ষিত হবে। টোকেন কোথাও সংরক্ষণ করা হয় না।

অনলাইন জরিপ তৈরি ও প্রকাশ

এই টোকেন শুধু জরিপ ও জরিপের ছবি প্রকাশে ব্যবহার হবে; কোথাও সংরক্ষণ করা হয় না।

প্রতিটি ছবি সর্বোচ্চ 5 MB। ছবি না দিলেও জরিপ প্রকাশ করা যাবে।

জরিপ প্রকাশের পর পাঠকেরা ওয়েবসাইটে ভোট দিতে পারবেন। ভোটের ফলাফল Firebase Realtime Database থেকে সরাসরি দেখানো হবে। Firebase Database Rules ঠিকভাবে সেট করা থাকতে হবে।
